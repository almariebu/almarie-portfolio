# Almarie Bu - Personal Portfolio

A simple static portfolio built with HTML, CSS, and JavaScript.

## Sections

- About
- Professional Experience
- Personal Projects
- Skills
- KyaNiSys
- Contact

## Before publishing

Update these placeholders in `index.html`:

- `YOUR_EMAIL@example.com`
- `YOUR_GITHUB`
- `YOUR_LINKEDIN`

Replace the `#` project links with your real GitHub repository URLs.

## Run locally

No build tools are required.

Open `index.html` directly in a browser, or use a simple local server.

Example:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## Deploy to Vercel

This is a static site. No framework or build command is required.

1. Push the folder to a GitHub repository.
2. Import the repository into Vercel.
3. Leave the build command empty.
4. Set the output directory to the project root if prompted.
5. Deploy.
